Hachukma in Action

Preview of the desktop input method software interface — v2.0

The notepad shows both Hachukma script and Roman transliteration side by side. Supports custom themes, word count, typing practice, and tone diacritic via double‑tap 'p'.

Notepad Features & Smart Transliteration

The Hachukma IME engine is built for efficiency and accuracy. Here's what you get out of the box:

Themes

Switch between light, dark, and other available color schemes. Reduce eye strain and choose a look that feels comfortable during long typing sessions.

Font Size

Adjust the displayed Hachukma font size in real time, from small to large, for a more comfortable reading and typing experience.

Visual Error Detection

If a word is typed using an incorrect character sequence, the IME engine automatically highlights the affected letters in red-strike. This provides instant feedback and helps identify mistakes while learning the correct character forms.

Save & Share

Save your typing preferences to a file and share it whenever needed. Anyone using the same software can load the file and instantly get the same typing experience without having to adjust anything manually.

Keyboard Guide (Input Key → Glyph)

Press these keys on your physical keyboard to type the corresponding Hachukma glyph. Each key represents a single consonant character & a regular vowel/digit.

Double‑tap p quickly → tone high diacritic  (custom diacritic – U+E024).

Unicode Reference (PUA Mapping)

PUA Codepoint Status — Hachukma uses U+E000 to U+E024

Hachukma currently does not use registered PUA code points and has not submitted any PUA registration proposal.

This status will remain until the Hachukma script is accepted by the Kokborok speakers. If the Kokborok speakers accept the script, then a PUA registration proposal will be made.

Future: If accepted by the relevant standards body, a formal proposal will be submitted to the Unicode Consortium to allocate official, universal codepoints for the Kokborok script.

Tone Glyph Metrics (U+E024) – Font‑Internal Values

These are the exact OpenType metrics and anchor coordinates used in the Hachukma-Regular.ttf font to position the tone high diacritic above the base letter. These values were tuned to work correctly in the Windows IME and on the web.

Width:0 (zero advance width – combining mark) Left Side Bearing (LSB):-100 Right Side Bearing (RSB):55 Anchor Type:mark (GPOS lookup “mark”) Anchor Name:top Glyph Origin:Bottom‑center at (0,0); shape extends upward (negative Y) Base Anchor (on letters):top, X≈500, Y≈top of letter (e.g., -600)

Note: The previous anchor X/Y offsets and negative RSB range have been superseded by the corrected LSB (-100) and RSB (55) values from the font file.
